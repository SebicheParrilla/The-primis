# Glossary

| Term | Definition |
|---|---|
| **AIZA** | Anti Insult Zapping Automaton, the name of our autonomous robot. |
| **eCVT** | Electronic Continuously Variable Transmission. A transmission system that electronically changes the effective drivetrain ratio instead of using fixed gears. |
| **Pneumatic Engine** | The compressed-air-powered engine used as the primary mechanical power source of AIZA. |
| **Flywheel** | A rotating mass connected to the pneumatic engine that helps stabilize its rotational motion and provides the input to the transmission. |
| **Planetary Gearset** | A gear system consisting of a sun gear, planet gears, and ring gear used to provide different transmission ratios. |
| **Differential** | A drivetrain mechanism that allows the two drive wheels to rotate at different speeds while transmitting torque to both wheels. |
| **Drivetrain** | The mechanical system responsible for transmitting power to the robot's wheels. |
| **Air Supply and Management System** | The system responsible for storing, regulating, and delivering compressed air to the pneumatic engine. |
| **UART** | Universal Asynchronous Receiver-Transmitter, the serial communication interface used between the Raspberry Pi and Cytron Motion 2350. |
| **IMU** | Inertial Measurement Unit. A sensor that measures motion and orientation using accelerometers, gyroscopes, and other sensing elements. |
| **Yaw** | Rotation of the robot around its vertical axis. It is used by AIZA to determine its heading during navigation and turning. |
| **HSV** | Hue, Saturation, and Value. A color representation used by the vision system to separate colored course markings from the environment. |
| **Vision-Based Navigation** | Navigation that uses camera data and image processing to determine the robot's position and required movement. |
| **State Machine** | A control structure in which the robot operates in defined states and transitions between them based on sensor inputs and conditions. |
| **Closed-Loop Control** | A control method that uses sensor feedback to compare the actual system state with the desired state and make corrections. |
| **Encoder** | A sensor used to measure rotational movement and determine the speed or position of a rotating component. |
| **Solenoid** | An electrically controlled valve used to control the flow of compressed air to the pneumatic engine. |
| **Raspberry Pi** | The single-board computer responsible for high-level vision processing, navigation, and communication. |
| **Cytron Motion 2350** | The RP2040-based controller responsible for low-level drivetrain and actuator control. |
