# Issue: Air Storage Duration Was Too Short
> Retrospective log: This entry's information was digitized from the physical engineering notebook on 2026-07-16.
## Problem

The V2.0  pneumatic engine could only operate for approximately **7 seconds** using four air tanks charged to **40 PSI**.

This runtime was too short to complete a full WRO run, so we investigated ways to increase the amount of stored compressed air without increasing tank pressure.




- Tank volume: **237 cm³**
- running time (at 40psi): **7s.**
- absolute pressure(used for calculations) 40+14.7 = **54.7 psia** 

### Pressure

For calculations, atmospheric pressure must be included.

```
40 PSI + 14.7 PSI = 54.7 PSI (absolute)
```

Using Boyle's Law:

```
Stored air = Pressure × Volume

54.7 PSI × 237 cm³
```

---

## Estimated Runtime

Measured runtime:

- 7 seconds using 4 tanks

Using the air proportion:

```
New Runtime = Test Runtime × New Pressure / Test Pressure

7 × (114.7 / 54.7)

≈ 14.6 seconds
```

---

## Proposed Solution

Increase storage pressure from:

- **40 PSI**
- to
- **100 PSI**

Absolute pressure:

```
100 PSI + 14.7 PSI = 114.7 PSI
```

Theoretical runtime:

**≈14.6 seconds**

---

## Results

Although the calculations predicted approximately **14.6 seconds**, the actual runtime was significantly higher.

Measured runtime:

**≈58 seconds**

---

## Analysis

The theoretical calculation assumes constant airflow throughout the discharge.

However, the pneumatic engine cannot effectively use air once the tank pressure becomes too low. Increasing the initial storage pressure keeps the engine operating within an efficient pressure range for a much longer period.

This demonstrates that increasing storage pressure provides a greater improvement than predicted by a simple proportional calculation.

---

## Conclusion

Increasing the storage pressure from **40 PSI** to **100 PSI** increased the runtime from approximately **7 seconds** to **58 seconds**, greatly improving the feasibility of using the pneumatic engine during a complete WRO match.
